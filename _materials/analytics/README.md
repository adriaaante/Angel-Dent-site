## Подпись студии (обязательно)

Любой отчёт для владельца выходит под маркой **FutureFlow**: логотип в
шапке каждой страницы, «Подготовлено FutureFlow · futureflow.ru» в подвале
и плашка в конце. Файл логотипа — `futureflow-logo.png` рядом со скриптами
(белый знак на синей плашке `#3C8AD8`, взят из папки Drive владельца
`1bzhwMnt0NT7E7UAYU2cGp_dZ49XgBzUf`). Вариант `_nourl.png` из той же папки —
белый на прозрачном, на белом листе не виден, не брать.

## Правила

- В таблицу попадают **только цены, опубликованные на сайте самой клиники**
  и проверенные открытием страницы. У каждой строки — кликабельная ссылка
  на источник, чтобы владелец мог убедиться сам.
- Числа из агрегаторов (ПроДокторов, Zoon, НаПоправку) идут **отдельным
  блоком «контекст»** с пометкой, что это данные агрегатора: клиника за них
  не отвечает, и они часто устаревают.
- Клиника не публикует цену — так и пишем («цену на сайте не публикует»),
  а не подставляем число из агрегатора.
- Суммы прогоняются через `nbsp()`: без неразрывного пробела «16 000 ₽»
  рвётся по строке как «16» / «000 ₽».
- Шрифт — Onest (статические срезы вырезаются из вариативного файла
  `_materials/kabinet/fonts/Onest[wght].ttf` через fontTools instancer).

## Пересборка

```
python3 _materials/analytics/otbelivanie-reutov.py
```

Цены живые — перед повторной выдачей владельцу **перепроверить каждую
ссылку**: прайсы клиник меняются, а отчёт с устаревшими цифрами хуже, чем
никакого.
