# SEO-материалы Ангел-Дент (для владельца; не деплоятся)

Диагностика по API (Вебмастер+Метрика) показала: **фильтров нет**, но
**ИКС = 20** (низкая авторитетность), сайт по гео-запросам на позициях 5–9.
Главный рычаг роста — **отзывы + агрегаторы + упоминания** (≈75% локального
веса), а не правки сайта. Здесь — материалы, чтобы это запустить.

- `qr-otziv-yandex.png` — QR на страницу отзывов Яндекс.Карт (распечатать на
  ресепшен/в кабинете/на визитках-памятках). Ведёт на карточку
  `yandex.ru/profile/1155929397`. Если в кабинете Яндекс.Бизнеса есть готовая
  «ссылка на отзывы» — лучше перегенерировать QR под неё (точнее открывает форму).
- `agregatory-i-otzyvy.md` — чек-лист размещения на агрегаторах, скрипт
  просьбы об отзыве и шаблоны ответов на отзывы.
